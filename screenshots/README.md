# Application Screenshots

This directory stores demonstration screenshots of the **Library Management System Using Python** for internship reports, project presentations, and GitHub documentation.

1. `01_main_menu.png` - Main application console menu (Options 1–11).
2. `02_add_book.png` - Adding new books with validation.
3. `03_view_all_books.png` - Formatted table displaying all books in inventory.
4. `04_search_books.png` - Case-insensitive and partial search results.
5. `05_issue_book.png` - Successful book issuing and stock decrement.
6. `06_prevent_unavailable_issue.png` - Validation blocking issue when stock is 0.

8. `08_prevent_duplicate_return.png` - Validation blocking double return.
9. `09_issue_records_table.png` - Formatted issue history table.
10. `10_summary_reports.png` - Library inventory and loan statistics.
11. `11_csv_export.png` - Exporting books and issue logs to CSV files.
